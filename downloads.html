Temp_Cleaner GUI supports Windows Server 2012 onwards. Which binary is right for my system?

Previous versions of Temp_Cleaner GUI (probably including this one) might be falsely detected as malware/PUP by many antivirus programs. Earlier versions used UPX to compress the executable and other binary files, which triggers many antivirus programs.

You can add Temp_Cleaner GUI's folder to your antivirus exclusions. Pick your antivirus to learn how:

  • Microsoft Defender (aka. Windows Security)
  • Avast Antivirus/Avast One
  • Avira Antivirus
  • MalwareBytes for Windows
  • McAfee Products

If your antivirus isn't listed, search the web for "How to add a [your antivirus] antivirus exclusion".
