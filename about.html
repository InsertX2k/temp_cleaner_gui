About Temp_Cleaner GUI

Temp_Cleaner GUI is a free, open-source Windows cleaning utility, engineered to give you back disk space with complete transparency. With more than 70 cleaning options, support for Windows 7 SP1 through Windows 11, and a live record of every file it removes, it delivers a thorough clean without the guesswork and without a single ad. It's made and maintained by Ziad (Mr.X), who also publishes as InsertX2k.

Downloaded more than 90,000 times and listed on Softpedia, MajorGeeks and OlderGeeks.

What sets it apart

Comprehensive coverage
More than 70 cleaning options reach well beyond temporary folders: WinSxS, Windows.old and Service Pack leftovers, plus the caches of leading browsers, games, creative tools and developer software. It can even clean a connected Android device over ADB.
Complete transparency
Every deleted file appears in a live log, and every session ends with a summary of the space recovered. Because the code is open source, you can verify exactly what it does.
Control over every clean
Cleaning presets, from Web Browser only to Maximum, let you choose how thorough each run should be, so a quick tidy-up and a deep clean are one click apart.
Built for the PC you have
Supports Windows 7 SP1 through Windows 11, with native 32-bit and 64-bit builds, so older machines are treated as first-class citizens.
Privacy by design
No ads and no personal identification data collected. Our privacy policy spells out, in plain terms, the little the program does touch.
Always up to date
A built-in updater keeps you informed when a new version is available, and a dedicated support community is there when you need help.

Version history

Since 2021, Temp_Cleaner GUI has grown through 29 releases, each one shaped by real users and their feedback. Here is the journey so far and where we are headed. Hollow dots mark pre-release builds.

  1. 2021: Foundations

    Temp_Cleaner GUI started small and found its footing fast. Within six months it gained a settings screen, live console output of what gets deleted, and its first accessibility options, with the source code open under the GNU GPL from the start.

  2. Apr 11, 2021v1.52-u3

    A fresh look for the most-used buttons, plus layout fixes. Source code published under the GNU GPL.

  3. Apr 27, 2021 - Aug 23, 2021

    A couple more fixes, strengthening what was built.

  4. Sep 24, 2021v3.2

    Accessibility options debut, alongside stability improvements and major UI changes.

  5. 2022: Making it friendlier

    This was the year we made it friendlier and faster: dark and light themes, Arabic language support, cleaning that is more than 10x faster, presets suggested by the MajorGeeks community, and a summary of the disk space each session frees.

  6. Feb 5, 2022v4.0

    Dark and light themes, switchable from Settings, with a new icon and banner.

  7. Feb 25, 2022v4.1

    Arabic language support for the interface.

  8. Mar 31, 2022v4.7

    Multithreading support: Now cleaning is more than 10x faster. Mouse-wheel scrolling added.

  9. Jun 5, 2022v4.8-betapre-release

    A first look at simpler code, easier translations and custom cursors.

  10. Jun 16, 2022v4.8-stable

    Cleaning presets, an idea from MajorGeeks, plus right-to-left layout for Arabic.

  11. Jul 2, 2022 - Sep 12, 2022

    Adding what was necessary for the completion of the recently added features.

  12. 2023: Staying current

    The built-in updater arrived in v5.6, so you no longer have to check the website. The rest of the year deepened what the program can clean, from WinSxS and Windows.old to Opera and offline web pages, while updater reliability kept improving.

  13. Jan 30, 2023v5.6-stable

    The built-in updater arrives, on a new customtkinter foundation with better low-resolution support.

  14. May 25, 2023v6.4-stable

    A big cleaning upgrade: WinSxS, Service Pack, Windows.old, offline web pages and all-drives Recycle Bin. Plus a Donators window.

  15. Jun 21, 2023v6.6-stable

    Better stability on older Windows, new Opera and Playnite cleaners, and a help document.

  16. Jun 23, 2023 - Jul 26, 2023

    Strengthening the recently added features.

  17. 2024: A new chapter

    Version 7 arrived in the autumn with a new set of capabilities: stopping a cleaning run midway, Android cleaning over ADB, post-cleaning power options and a progress bar. We also stopped compressing the program with UPX to cut down on false antivirus detections.

  18. Sep 2, 2024v7.0-testingpre-release

    Stop a cleaning run midway, clean Android devices over ADB, pick a power action afterwards, and clean BeamNG.Drive temp files.

  19. Oct 3, 2024v7.0-stable

    A progress bar for cleaning runs and an Android cleaner that asks which connected device to clean.

  20. Oct 25, 2024v7.1-stable

    An option to rebuild the Windows icon cache, a better thumbnail cleaner, and sturdier error handling.

  21. Present: looking forward

    Temp_Cleaner GUI keeps evolving, with more new features and improvements to meet users' expectations and keep pace with advances in software. We're looking forward to what comes next, and your feedback helps shape it. Follow along on GitHub.
